# DragonRebirth

Respawns the Ender Dragon for every player who reaches the End for the first time, so everyone on a multiplayer server gets their own fight, egg and full 12,000 experience.

**Status: in development, no features yet.**

## Planned behaviour

- A player enters the End (or logs in there) for the first time and no dragon is alive or respawning: the four end crystals are placed and the vanilla respawn sequence starts.
- The fight counts as a first kill, so the dragon drops the egg and 12,000 experience instead of 500.
- Everyone who damaged the dragon is remembered and never triggers another respawn.
- As in vanilla, a respawn rebuilds the obsidian pillars (destroying whatever is built on them) and each kill opens a new end gateway, up to 20.

## Requirements

Paper 26.2, Java 25.
